# Mindaso
A Balatro mod that adds new things to the game, not meant to be taken seriously whatsoever.

Currently adds:

95 new Jokers, 8 of which being legendary.
35 new Consumables, and a new consumable type, Mixotic.
8 new Booster Packs.
5 new Seals.
3 new Sounds.
4 new Editions.
and 10 new Enhancements.

Hope you enjoy!
